Question:
What is my RMV appointment confirmation code and why do I need it?

Answer:
A confirmation code is a reference number tied to your scheduled appointment. You should receive it after your appointment is successfully booked. Keep the code in a safe place and bring it to your appointment if you are asked to verify your booking.

If you need to check appointment details later, provide the confirmation code exactly as it was given to you. If the code is not recognized, double-check the number and try again. If it still does not work, use official RMV contact options on Mass.gov for help.

Notes:
- A confirmation code is provided after booking; it is not something you choose yourself.
- Do not share your confirmation code publicly on social media or with unknown third parties.
- If you lose your code but still have your appointment email, use the official myRMV appointment lookup tools first.
